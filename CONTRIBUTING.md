# Contributing to Library School System

Thanks for helping with the project.

## Project Goal
This repository is a school library system project. It is meant to be shared with groupmates and used for collaboration.

## Workflow
1. Fork or clone the repository.
2. Create a new branch for your work.
3. Make changes only in the relevant files.
4. Test your changes in the browser.
5. Commit the work with a clear message.
6. Push and create a pull request if needed.

## Folder Guidance
- `src/pages/` - page screens and UI modules
- `src/js/` - main logic, routing, and app state
- `src/css/` - styles
- `src/assets/` - images and static files
- `index.html` - entry page

## Code Style
- Keep file names descriptive.
- Use clear comments when needed.
- Avoid breaking existing page navigation.
- Test every feature after editing.

## Collaboration Tips
- Split the work by page or feature.
- Keep changes small and focused.
- Communicate before editing shared files.

## Submission Checklist
- Code runs without errors
- UI loads correctly
- No broken links
- Files are saved in the correct folders
- README is updated if necessary

## Questions
Ask the group leader or project owner before changing major features.
